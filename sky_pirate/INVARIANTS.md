# 天空海盗事件流：状态不变量与失败回滚

修复后的命令位于 `main.py`（即题目所称的事件流模块）。

## Bug 与命令对应

| 命令 | 修复点 |
| --- | --- |
| `cmd_a` | 重复劫掠：同一目标只劫掠一次 |
| `cmd_b` | 先到目标未攻击：`max` 改为 `min`，取到达时间最早者；空事件流返回 `None`（空事件不返回文本） |
| `cmd_c` | 船队满仍编入：容量检查前置，满员拒绝 |
| `cmd_d` | 单次劫掠重复累计：一次劫掠只结算一次 |
| `cmd_e` | 查看目标误删：只读取队首 `queue[0]`，不弹出 |
| `cmd_f` | 弹药少算：`len(items)-1` 改为 `len(items)` |
| `cmd_g` | 读档跳号：先返回当前 `next_id` 再自增 |
| `cmd_h` | 劫掠扣减/重复累计：存量不足 10 时不扣减、不透支 |
| `cmd_i` | 暂停仍前进：`closed` 为真时返回 `False`，事件流不推进 |
| `cmd_j` | 重置不清：重置真正清空事件流，且重复重置被拒绝 |

## 状态不变量表

| 编号 | 不变量 | 涉及命令 | 违反时的结果 |
| --- | --- | --- | --- |
| I1 | 任一 `target` 在 `state["plundered"]` 中至多出现一次 | `cmd_a` | 重复劫掠返回 `False`，集合不变 |
| I2 | 被攻击事件是 `events` 中到达时间（元组第 0 项）最小者 | `cmd_b` | 取 `min`；空流返回 `None` |
| I3 | `len(fleet) <= fleet_cap`（默认容量 0） | `cmd_c` | 满员返回 `False`，`fleet` 不增长 |
| I4 | 每次劫掠 `plunder_recorded` 只翻转一次 | `cmd_d` | 第二次结算返回 `False`，不重复累计 |
| I5 | 查看操作不改变队列长度与顺序 | `cmd_e` | 只读 `queue[0]`，无删除 |
| I6 | 上报弹药数 `== len(items)` | `cmd_f` | 不少算一件 |
| I7 | `next_id` 单调连续：分配 N 后才变为 N+1，无空洞 | `cmd_g` | 读档后首号为存档值，不跳号 |
| I8 | 扣减后 `src >= 0`，且成功时 `src + dst` 守恒（每次转移 10） | `cmd_h` | 不足时 `src/dst` 均不变 |
| I9 | `closed=True` 时事件流不推进 | `cmd_i` | 返回 `False`，状态不变 |
| I10 | 重置后 `events == {}` 且 `events_reset=True`，重置幂等 | `cmd_j` | 重复重置返回 `False` |

## 两条可重复的失败回滚路径

### 路径一：劫掠存量不足 → 全量回滚（`cmd_h`）

前置：`state = {"src": 5, "dst": 0}`。

1. 调用 `cmd_h(state)`，因 `src < 10` 返回 `False`。
2. 回滚断言：`state["src"] == 5` 且 `state["dst"] == 0`——扣减前校验，零写入，无半扣状态。
3. 补足存量（如 `src=20`）后重新调用，返回 `True`，`src=10, dst=10`，`src+dst` 仍为 20（I8 守恒）。

该路径可重复：每次从 `src=5` 出发结果完全一致。

### 路径二：读档后编号分配失败 → 不跳号重试（`cmd_g`）

前置：`state = {"next_id": 7}`（模拟刚读档）。

1. 调用 `cmd_g(state)` 返回 `7`（读档后的第一个编号），随后 `next_id` 变为 `8`。
2. 若调用方在拿到编号后写入事件失败而回滚：将状态恢复为 `{"next_id": 7}`（或在成功提交前不自增——当前实现先读后增，调用方可直接丢弃结果重试）。
3. 再次调用 `cmd_g` 仍返回 `7`，不会因为上次失败尝试跳到 `8`（I7），编号连续。

可重复复现：重置回 `next_id=7` 后重试，返回值恒为 `7`，无空洞。
