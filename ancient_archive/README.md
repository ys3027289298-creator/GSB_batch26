# ancient_archive 古代档案馆检索保存

## 引擎规则修正 (engine.py)

- 空书架返回 `None`, 不再返回占位文本
- 查看队首典籍只读不删, 先到典籍留在队列等待归档
- 重置将检索计数清零
- 烛火不足 20 拒绝扣除且余额不变; 剩余烛火 = 上限 - 已用, 不少算
- 缺失档案按 0 处理
- 档案馆默认锁定, 锁定期间禁止检索
- 单次检索事件处理后清空, 不重复累计
- 书架满 (used >= cap) 拒绝放入
- 移除节点时连同关联边一起清理

## 存档行为 (save.py)

### 暂停恢复
- `save_game(state, slot)` 原子写入槽位(临时文件 + rename), 中途崩溃不留残档
- `load_game(slot)` 逐项还原队列顺序、烛火、计数、典籍编号, 不跳号不丢项
- 读档幂等: 重复读同一槽位结果相同, 不推进任何计数器
- 槽位号从 0 连续递增 (`next_slot`), 同槽位再存覆盖旧档

### 损坏存档
- 槽位不存在: 返回 `None`, 不抛异常
- 内容损坏 / 校验和不匹配 / 版本不符: 返回 `None`, 原文件备份为 `<存档>.corrupt`
- 读档失败绝不修改调用方内存状态
